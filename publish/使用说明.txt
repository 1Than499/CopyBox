CopyBox v3.0.4 - 现代化贴边毛玻璃双模抽屉 & 离线生产力中枢
==================================================

【🔥 v3.0.0 四大旗舰模块重磅升级】
1. 🖼️ Windows 原生离线 OCR 文字提取与“以文搜图”：
   - 0MB 外部依赖、100% 纯本地离线：调用 Windows 10/11 原生 OCR 引擎，截图复制后后台自动提取图中文字并建立索引；
   - 以文搜图：在搜索框输入关键词即可直接搜出包含该文字的历史截图（高亮显示“🔍 命中图中文字”）；
   - 一键提取文字：图片卡片右上角自动浮现 [ 📝 提取文字 ] 按钮（历史旧图片点击亦支持即时识别），一键复制图中纯文本。

2. 📱 局域网离线双向快传（手机免安装扫码秒传）：
   - 点击侧边栏顶栏 [ 📱 ] 按钮即可生成局域网离线二维码；
   - 手机与电脑处于同一 Wi-Fi / 热点下，用手机相机或浏览器扫码即可免安装打开快传页面：手机发文字/发照片秒进电脑剪贴板，电脑复制的内容手机端一键获取；
   - 全程 100% 局域网本地直连，内置一次性会话安全令牌与敏感数据脱敏，关闭面板即刻释放端口，日常 0 内存开销。

3. 🏷️ 动态分类标签药丸栏 & 智能模板变量：
   - 分类药丸栏支持鼠标滚轮横向丝滑滚动，点击末尾 [ ＋ ] 按钮可自由新建带 Emoji 的自定义分类标签（如：💬 常用回复、🗄️ SQL片段、🤖 Prompt），右键药丸可删除分组；
   - 点击卡片右上角 [ 🏷 ] 按钮可将卡片归入自定义标签，所有归入自定义标签的卡片在“清空历史”时永久免删；
   - 支持动态模板宏变量：{{date}}、{{time}}、{{datetime}}、{{year}}、{{weekday}}、{{clipboard}}、{{guid}}，复制或粘贴时自动单遍替换为实时值。

4. ✨ Windows 11 原生云母/亚克力材质与微触感音效：
   - 在偏好设置中支持切换【🎨 经典高帧率毛玻璃】、【☁️ Win11 原生云母材质 (Mica)】与【💎 Win11 原生亚克力材质 (Acrylic)】（Win10 自动优雅降级）；
   - 支持开启【🔊 轻量微触感音效】，纯内存合成柔和正弦波微音效（复制捕获、抽屉弹出、贴入确认），并在全屏游戏免打扰模式下自动静音。

5. 🛡️ 全面继承 v2.2.2 极致轻量化与隐私防护：
   - 单文件内嵌 SQLite 原生引擎，自动秒建数据库（clipboard.db，兼容 clipvault.db）；
   - 后台彻底静默休眠 + 400px 缩略图约束解码 + UI 容器虚拟化回收 + EmptyWorkingSet 物理内存整理；
   - 全屏游戏自动防误触免打扰、多显示器跟随鼠标/固定主屏、左右贴边自由切换、6 类敏感信息（API Key/密码/银行卡/身份证/手机号）自动打码。

【快速上手】
1. 双击 CopyBox.exe 即可直接运行，纯绿色免安装，不向注册表写入任何残留信息；
2. 全局默认呼出/隐藏快捷键：Alt + V，或将鼠标移至屏幕贴边边缘自动唤出侧边栏；
3. 按数字键 1~9 直接秒贴对应项目，或鼠标按住卡片直接拖拽到目标软件窗口释放粘贴；
4. 点击顶栏 [ 📱 ] 即可扫码与手机双向互传文字和照片；点击分类栏 [ ＋ ] 即可创建常用短语标签。
