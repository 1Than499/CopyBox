【v2.2.2 核心更新与修复】
1. 🛠️ 彻底修复单文件便携运行无法自动建库与复制不显示 Bug：
   - 将底层原生 SQLite C 引擎（e_sqlite3）深度内嵌固化至 CopyBox.exe 内部，彻底消除外部 DLL 依赖；
   - 纯净环境下首次运行 100% 自动秒建数据库（clipboard.db，且完美双向兼容历史 clipvault.db）。
2. 🚀 极限轻量化重构，内存占用骤降 ~67%（前后台彻底休眠分离）：
   - 后台静默守卫：后台隐藏收起时彻底切断卡片全量 UI 渲染，终结“后台前台一样大”；
   - 图片按需像素约束：卡片预览缩略图约束至 400px 解码，单张 4K 截图解码内存开销降低 95%+，收起时自动清理临时图片缓存；
   - 满血 UI 虚拟化：开启 VirtualizingStackPanel 像素级容器回收，视口外卡片即刻释放，长历史零内存暴增；
   - 音频与边缘检测动态休眠：后台收起时暂停媒体轮询，边缘检测仅在光标触及 6px 热区时触发检测；
   - 物理内存工作集收缩：收起至贴边/托盘时主动触发轻量 GC 并调用 Windows EmptyWorkingSet，物理内存立即归还系统；
   - .NET 8 DATAS 动态自适应堆：启用工作站 GC 与 DATAS 模式，日常内存平稳在 50MB~65MB 左右，回归“极致小巧”初心。
3. 🎮 继承 v2.2.1 旗舰特性：全屏游戏与演示自动防误触免打扰、多显示器左右贴边自由、敏感信息自动脱敏打码。

【快速上手】
1. 双击 CopyBox.exe 即可直接运行，纯绿色免安装，不向注册表写入任何残留信息；
2. 全局默认呼出/隐藏快捷键：Alt + V，或将鼠标移至屏幕贴边边缘自动唤出侧边栏；
3. 复制任意文字、图片、代码后，按 Alt + V 即可在桌面贴边抽屉中一览无余；
4. 按数字键 1~9 直接秒贴对应项目，或鼠标按住卡片直接拖拽到目标软件窗口释放粘贴；
5. 点击卡片右上角 [...] 或单击右键，可进行常用项置顶、顺序连续粘贴与删除。

【双模视图自由切换与 100% 设置互通】
- 点击右上角 [⚙️ 设置] 图标，可在【贴边抽屉模式 (v2.0)】与【居中弹窗模式 (v1.0)】之间随时切换，两边所有设置项 100% 实时双向同步；
- 提供 6 款预设高级主题（暗黑、明亮、极光、暮色、深海）并支持自由上传本地图片作为背景壁纸。

【100% 物理离线与根目录便携存储】
- 本软件绝对 100% 本地离线，不发起任何网络请求，零遥测上报，彻底保障您的账号、密码与隐私数据安全；
- 默认将配置文件 settings.json、本地数据库 clipboard.db (兼容 clipvault.db) 及图片缓存保存在程序所在根目录，运行后自动创建并初始化；
- 可在设置中自由更改数据存储路径，轻松搭配 OneDrive / 坚果云等实现私有加密多端同步。
