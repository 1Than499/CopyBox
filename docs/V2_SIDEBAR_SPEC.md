# CopyBox v2.0 架构与规格说明书：贴边毛玻璃双模抽屉 (Sidebar Acrylic Drawer)

## 1. 概述与核心定位 (Overview & Positioning)

在 CopyBox v1.0 中，我们成功实现了 **“毫秒唤醒、全键盘秒贴、纯本地 SQLite WAL 存储”** 的现代 Windows 居中浮窗（`QuickPasteWindow`）。  
在 **v2.0 大版本更新** 中，CopyBox 将迎来全新的旗舰形态——**贴边毛玻璃双模抽屉（Sidebar Acrylic Drawer）**。

### 1.1 用户核心诉求与场景突破
- **痛点解决**：居中浮窗（Alt+V）专为“单次查找即贴即走”优化，但在密集写作、Excel 制表、多源资料采集等场景下，用户需要一个**长期在视野一侧、不挡核心工作区、可连续点击/拖拽内容**的侧边工作台。
- **1:1 原生级系统看板整合**：借助 Windows 10/11 右侧操作中心（Action Center）相同的屏幕位置与亚克力（Acrylic）视觉材质，在顶部集成 **双模切换开关**，使用户在 **“CopyBox 剪贴板知识流”** 与 **“系统通知与快捷磁贴看板”** 之间毫秒级平滑切换，打造真正浑然一体的桌面伴侣。

### 1.2 双轨共存与 v1.0 永久保留策略 (Dual-Track Preservation)
- **非破坏性升级**：v2.0 绝不替换或删除 v1.0 原有特性，而是作为向下兼容的超集。
- **Git 存档与 Release 分离**：
  - v1.0 经典版已在 GitHub 远端永久冻结并打上 Release Tag `v1.0.0`，并建立 `v1.0-classic` 分支归档；
  - 提供独立的单文件绿色安装包 `CopyBox-v1.0.exe` 供偏好极致极简的用户永久下载使用；
- **运行时形态自由切换**：
  - 在 CopyBox 设置中引入“界面形态”切换：用户可随时在 **`[ 🪟 v1.0 经典居中极速浮窗 ]`** 与 **`[ 📱 v2.0 贴边毛玻璃双模抽屉 ]`** 之间自由切换，满足不同场景下的操作习惯。

## 2. 极致轻量化核心铁律 (Lightweight Principles)

用户明确要求 **“依然要保持极致轻量化”**。CopyBox 绝不妥协引入 Chromium、Electron、WebView2 等臃肿前端渲染器，全部基于原生 **.NET 8 WPF + Win32 API + DirectComposition** 构建：

| 关键指标 | 约束指标与实现策略 |
| :--- | :--- |
| **常驻内存 (RAM)** | **≤ 40MB ~ 50MB**（闲置自适应压缩工作集，GC 零泄漏） |
| **唤醒延迟 (Latency)** | **< 16ms（60Hz 满帧启动）**，窗口预热常驻后台，滑出不触发冷启动 |
| **UI 虚拟化 (Virtualization)** | 侧边栏即使累积 10,000+ 条历史记录，也仅对当前视口可见的 12~15 张卡片进行实例化渲染（`VirtualizingStackPanel` + `Recycling`） |
| **零常驻侵入性** | 不 Hook 篡改 Windows Explorer / `ShellExperienceHost.exe` 进程，无任何第三方注入报毒风险 |
| **零云端网络开销** | 维持 100% 物理本地存储，无任何后台网络心跳或数据遥测包 |

## 4. 关键交互特性与技术实现 (Key Features & Tech Specs)

### 4.1 无焦点点击与直接粘贴 (`WS_EX_NOACTIVATE`)
- **技术要点**：通过 Win32 API 为 `SidebarWindow` 赋予 `WS_EX_NOACTIVATE` (0x08000000) 与 `WS_EX_TOPMOST` 窗口扩展样式。
- **效果**：用户在 Word、IDE、Excel 等活动窗口输入时，鼠标点击侧边栏的任何卡片，**主窗口的光标闪烁焦点绝不丢失**；同时通过 `PasteSimulator.SimulatePasteAsync()` 直接将内容送达目标输入框。

### 4.2 鼠标拖拽释放 (Drag & Drop Out)
- 侧边栏卡片原生支持 `DoDragDrop`，用户可按住左键将文字、代码块直接拖入任何支持 OLE 拖放的文本编辑器，或将图片文件对象拖入聊天软件或文件管理器。

### 4.3 贴边自隐藏与吸附感应 (Edge Auto-Hide)
- **图钉解锁状态 (Unpinned)**：抽屉滑出后，当鼠标离开侧边栏区域 800ms，抽屉自动向右缩进，仅在屏幕最右侧保留 2px 的呼吸半透明光条（低能耗鼠标光标感应热区）；鼠标再次碰触屏幕右边缘立即顺滑滑出。
- **图钉锁定状态 (Pinned)**：抽屉常驻最右侧，始终悬浮在顶层，方便多任务对照。

### 4.4 系统操作磁贴极轻量联动
- 快捷操作磁贴（如蓝牙、夜间模式、网络、屏幕截图）通过 Windows 原生 URI 协议或轻量 Win32 指令触发：
  - 屏幕截图：`ms-screenclip:`
  - 所有设置：`ms-settings:`
  - 蓝牙面板：`ms-settings:bluetooth`
  - 网络面板：`ms-settings:network`
  - 原生操作中心一键唤起：模拟 `Win + A` (VK_LWIN + VK_A)

## 5. 路线图与分阶段实施计划 (Milestone Roadmap)

- **阶段一 (Phase 1)：侧边栏基础骨架与毛玻璃贴边 (v2.0-alpha)**
  - 构建 `SidebarWindow.xaml` 视图，配置右贴边定位算法与多 DPI 适配；
  - 启用 `WS_EX_NOACTIVATE` 与亚克力模糊滤镜；
  - 实现从屏幕右侧平滑滑出/收起的贝塞尔曲线动画。
- **阶段二 (Phase 2)：双模 Tab 切换与系统磁贴仿生 (v2.0-beta)**
  - 实现顶部切换 Tab：`[ 📋 剪贴板中心 ]` ⇋ `[ 🔔 系统快捷看板 ]`；
  - 构建 4×4 磁贴网格与系统设置协议联动；
  - 增加无缝呼叫系统原版 `Win+A` 的透传按钮。
- **阶段三 (Phase 3)：边缘自隐藏、拖拽粘贴与全键盘联动 (v2.0-release)**
  - 完善鼠标贴边感应热区与图钉锁定机制；
  - 增加全键盘焦点切换（`Tab` / 方向键）与拖拽（Drag & Drop）；
  - 完善中英多语言与设置选项联动。
